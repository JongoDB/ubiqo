# ADR-0001: License ubiqo under Apache-2.0

**Status:** accepted · 2026-07-13

Apache-2.0 with DCO sign-off; trademark policy and a "free-forever charter" (single-org self-host stays complete and free; future revenue = managed cloud, multi-org federation, compliance exports, SLA support) to be published in the README before public launch.

**Why:** the moat is integration + templates + ecosystem, not code secrecy. AGPL would chill the enterprise adopters who fund the future business; open-core remains viable atop Apache. Matches requirement 1's spirit and the business review's recommendation. Decided pre-first-public-commit while the copyright holder is singular.
